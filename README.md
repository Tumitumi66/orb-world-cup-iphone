# 小球世界杯 · iPhone Safari 版

128队候选池 / 32强淘汰赛 / 一对一自由碰撞 / 实体盾牌 / 22种武器道具。

## 手机打开

使用 iPhone Safari 打开 GitHub Pages 网站。点击开始或试听启用音效。可通过“分享 → 添加到主屏幕”安装。首次联网打开并完成离线缓存后可离线游玩。

已针对 Safari 做 PCM WAV 音效、触屏按钮、安全区、竖横屏与后台暂停处理。返回手机前台后点击继续。赛程和进行中的比赛保存在本机浏览器。

## GitHub Pages 发布

将这个文件夹里的文件上传到公开仓库根目录。进入 Settings → Pages，Source 选 Deploy from a branch，Branch 选择当前默认分支及 / (root)，保存后等待 GitHub 发布。网站入口为 index.html。所有资源路径均支持仓库子目录。

代码不依赖构建工具、服务端或密钥。游戏资源已内嵌，授权说明见 ASSET-LICENSES.txt。当前候选池是自定义邀请赛名单，并非某届世界杯真实晋级名单。
